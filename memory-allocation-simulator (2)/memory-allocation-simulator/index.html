Research Mode – Dynamic Heap Evaluation

Approach from Al Abdi, Alqudah & Helmy (Contiki-NG heap study): the allocation strategy is a replaceable part of a heap that handles allocation and release. First Fit, Best Fit and Worst Fit replay the same random workload; results are averaged over several runs.

Best value in each column is highlighted. Search steps = free blocks examined per request (hardware-independent proxy for allocation time).

Parameter Definitions

  • Utilization – requested bytes in use ÷ heap size, averaged over all events.
  • Internal fragmentation – (allocated − requested bytes) ÷ heap size (alignment and unsplit leftovers).
  • External fragmentation – 1 − (largest free block ÷ total free memory); high = free space is scattered.
  • Failure rate – failed requests ÷ all requests.
  • Search steps – free blocks examined per request.
